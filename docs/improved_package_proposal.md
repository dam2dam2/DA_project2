# ✈️ 하나투어 패키지 상품 개선 제안 리포트
## (부정 리뷰 및 저평점 데이터 기반 분석)

## 1. 개요
본 리포트는 `hanatour_sentiment_result.csv` 데이터에서 평점 3.0 이하 및 감성 분석 결과 '부정'으로 분류된 리뷰 약 1,286건을 분석하여 작성되었습니다. 고객의 실제 목소리를 바탕으로 현재 패키지의 문제점을 진단하고, 이를 획기적으로 개선한 새로운 상품 모델을 제안합니다.

---

## 2. 핵심 불만 요인 (Pain Points)
부정 리뷰에서 반복적으로 언급되는 4대 핵심 불만 요인은 다음과 같습니다.

| 요인 | 주요 내용 |
| :--- | :--- |
| **선택 관광 강요** | 선택 관광(옵션) 미참여 시 차량에서 장시간 대기하게 하거나, 가이드가 눈치를 주어 사실상 강제로 참여하게 함. |
| **과도한 쇼핑** | 일정 중 반나절 이상을 원치 않는 쇼핑 센터 방문에 할애함. 구매 압박으로 인한 스트레스 유발. |
| **일정 과밀** | 오전 일찍 시작하여 밤 9~10시에 종료되는 빡빡한 일정. 호텔 시설(수영장 등)을 이용할 시간이 전혀 없음. |
| **위생 및 품질** | 이동 차량(버스)의 청결도 불량(바퀴벌레 등), 제휴 마사지 샵의 위생 문제로 인한 피부 트러블 발생. |

---

## 3. 개선된 패키지 상품 제안
위의 불만 요소를 원천 차단하고 고객 만족도를 극대화할 수 있는 **'하나투어 온전한 휴식'** 패키지를 제안합니다.

### 🌟 상품명: [No쇼핑/No강요] 다낭/호이안 5일 #6시체크인 #마스터가이드 #프리미엄위생

### ✅ 주요 개선 사항 (Unique Selling Points)
1. **완벽한 'No 쇼핑, No 강요' 정책**
   - 쇼핑 센터 방문 횟수를 0회로 고정합니다.
   - 모든 필수 관광지를 상품가에 포함하고, 선택 관광은 '호텔 휴식' 또는 '자유 시간' 옵션을 명확히 제공합니다.
2. **'6시 귀가' 보장 시스템**
   - 모든 외부 일정을 오후 6시 이전에 종료합니다.
   - 저녁 시간은 호텔 내 수영장, 스파, 라운지를 충분히 즐길 수 있도록 보장하여 '진성 휴식'을 제공합니다.
3. **위생 안심 인증제 (Sanitize-Pure)**
   - 매일 전문 방역 업체가 소독하는 전용 차량만 배차합니다.
   - 제휴 마사지 및 식당은 월 1회 불시 위생 점검을 통과한 곳으로만 엄선합니다.
4. **투명한 가격 정찰제**
   - 현지 옵션 비용이 한국 내 직접 예약가보다 과도하게 비싸지 않도록 가격을 평준화합니다.

---

## 4. 기대 효과
- **고객 충성도 제고**: 쇼핑과 옵션 강요에 지친 고객들에게 신뢰할 수 있는 프리미엄 브랜드 이미지를 구축합니다.
- **긍정 리뷰 확산**: 호텔 시설 이용에 만족한 고객들이 개인 SNS 및 리뷰 게시판에 자발적인 홍보 콘텐츠를 생산할 확률이 높습니다.
- **재방문율 증가**: '피곤한 패키지'가 아닌 '다시 오고 싶은 여행'으로 포지셔닝하여 높은 재방문율을 기대할 수 있습니다.
